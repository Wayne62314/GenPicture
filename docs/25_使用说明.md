# 25｜整图风格统一重绘

独立于24的新工作流，不覆盖24。

## 与24的差别

内部顺序改为：身份与构图 → 场景 → 表情 → 整图风格 → 可选精修 → 超分。

风格放到最后，避免场景编辑重新带回场景图的写实材质。完整风格模式明确允许重新绘制人物、动物、道具、建筑、地面、植被及天空的轮廓、材质和阴影，保留的是内容、身份与空间关系，不是原画的笔触和细节纹理。

## 使用方式

原图/文字起点、角色身份、动作、场景、表情、全局负面词和超分沿用24。

想整张图统一画风：

1. 开启风格参考，选择上传或AI来源。
2. 将风格范围设为“开＝完整”。
3. 右侧“整图风格补充”已按当前例子填写动漫画法，特别说明马匹也要采用简化造型、明确轮廓和赛璐璐色块，背景采用动画背景画法。
4. 运行后比较“② 场景与表情完成后”和“③ 全图统一画风后”。

风格参考只有角色特写时，它并没有直接展示马匹和大场景该怎么画，所以补充文字是对目标画法的人工说明，不是自动从截图提取。换成水彩、油画等目标风格时，需要修改或清空这段补充。

只借某种特点：范围设为关，填写该列的“指定特点”。此时整图风格补充不进入提示词，不会强制全图动漫化。

## 身份与负面词

默认保留24的文字身份保护，当前为波奇；换角色需同步更新右侧身份特征。更强的图像身份保护可选，但可能压制画风迁移。

负面词仍统一参与所有阶段，CFG默认1.5。它不能保证消除所有多余肢体。完整重绘也可能改变细节；严格局部保留需要蒙版。

### 实际测试（2026-10-09）

`Qwen25_global_style_00001_.png` 生成成功。对照风格处理前的 `Qwen25_debug/02_content_00001_.png`：马匹的写实毛发与油画明暗已转成描边、简化鬃毛和色块阴影，建筑、植被、道路及天空也采用统一的二维动画画法；波奇身份和骑马构图基本保留。

本例验证了全图动漫化，不代表精准复刻《龙女仆》的制作画风。原深夜氛围被提亮，局部细节也有变化：全图重绘仍不能保证严格保留光照、像素和所有解剖细节。
