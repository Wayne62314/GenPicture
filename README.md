# GenPicture

ComfyUI 中文工作流。当前收录 **25｜综合生图：整图风格统一重绘**。

## 下载与导入

- [下载工作流 JSON](workflows/25_综合生图_整图风格统一重绘.json)
- [查看详细中文说明和测试记录](docs/25_使用说明.md)

下载 JSON 文件后拖入 ComfyUI 画布，或通过工作流的打开功能导入，再保存到自己的工作流列表。

仓库保存的是工作流配置，**不包含模型权重、参考图片或生成结果**。文件中原有的图片文件名只是本地引用；导入后需要上传自己的图片并重新选择。若 ComfyUI 提示缺失输入，请先完成对应图片选择。

## 能做什么

- 从文字与参考图创建画面，或上传原图作为编辑起点。
- 分别控制角色身份、动作与镜头、场景、表情和风格；每类参考可选上传或 AI 生成。
- 选择完整参考本类内容，或仅采用指定特点，例如只借场景灯光。
- 在场景、表情完成后统一全图画风，让人物、动物、道具和背景一起转换。
- 提供全局负面提示词、可选蒙版精修、2 倍超分和自动保存的阶段结果。

内部顺序：**身份与构图 → 场景 → 表情 → 整图风格 → 可选精修 → 超分**。

## 环境与模型

已验证环境为 ComfyUI **0.39.0**、前端 **1.53.10**、RTX 5080 16GB。这是验证记录，不是严格的最低版本要求；需要包含工作流所用的 Qwen-Image 2.1 和逻辑/文本节点。

主要节点包括 `TextEncodeQwenImage21`、`QwenImage21Cache`、`ComfySwitchNode`、`StringConcatenate` 和 `StringReplace`。高级分支还涉及 `ZImageFunControlnet`。

模型按下表放进 ComfyUI 的 `models` 目录，或在自己的模型路径配置中提供同名文件：

| 文件 | 目录 | 用途 |
|---|---|---|
| `qwen_image_2.1_int8_convrot.safetensors` | `diffusion_models/` | 主模型 |
| `qwen3vl_8b_int8_convrot.safetensors` | `text_encoders/` | 文本与视觉编码 |
| `qwen_image_2.1_vae_bf16.safetensors` | `vae/` | 图像编解码 |
| `qwen_image_2.1_fun_controlnet_union_int8_convrot.safetensors` | `model_patches/` | 高级结构控制、蒙版精修分支 |
| `RealESRGAN_x4plus_anime_6B.pth` | `upscale_models/` | 可选超分 |

可选分支默认不需要执行，但前端仍可能提示缺少对应模型；使用该分支前必须安装或在加载节点选择兼容模型。依赖请以导入后的节点提示和 ComfyUI 实际校验为准。

## 快速使用

1. 选择起点：开＝上传原图编辑，关＝从文字/参考新建。
2. 在“成图/编辑要求”填写英文提示词；原图编辑时写需要修改的内容。
3. 上传需要的参考，开启相应栏目，选择来源和参考范围。
4. 要统一整张图的画风，开启风格参考，并将范围设为“完整”。
5. 检查右侧“身份特征补充”和“整图风格补充”。当前示例预填波奇及动漫骑马画面；换角色、题材或画风时需要同步修改或清空相关描述。
6. 运行并比较阶段预览，最终图片自动保存。

基础要求通常不需要手动填写图片编号。各栏目会自动分配参考用途；“指定特点”文本框中的默认示例保留了内部使用的图片标签，修改时请遵循示例。

## 已知限制

- 身份特征和整图风格补充是人工填写的文字，不是从图片自动提取。
- 完整重绘可以改变细节和光照。已测试的骑马样例实现了全图动漫化，但夜景被提亮，不代表精确复刻某部作品的画风。
- CFG 默认 1.5；本机标准采样在 CFG＝1 时会跳过负面分支。负面词不能保证消除所有解剖错误。
- 强身份图保护可能抑制风格迁移；严格局部保留需要蒙版与合成。

工作流以中文标注和说明为主，生成指令主要使用英文。完整测试记录见[使用说明](docs/25_使用说明.md)。
